# far-github-panel

A read-only Far Manager 3 panel plugin for browsing GitHub: your account and
organizations, their repositories, branches, tags, releases and file trees.
F3 to view, F5 to copy to your PC.

- Target: Far Manager **3.0.6638+**, **Windows x64**
- Login: reuses your **`gh` CLI** login automatically (or `GH_TOKEN` /
  `GITHUB_TOKEN`, or a token saved in the plugin's settings)

Download from the [Releases](../../releases) page. Usage:
[docs/PLUGIN-README.txt](docs/PLUGIN-README.txt). Design:
